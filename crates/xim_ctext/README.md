# xim-ctext

Vendored copy of [`xim-ctext`](https://github.com/Riey/xim-rs) by Riey,
MIT licensed (see `LICENSE`). Encodes and decodes X11 compound text, the
encoding XIM uses for preedit and commit strings.

Only used by `crates/xim`. See [`../xim/README.md`](../xim/README.md) for why
these crates are vendored and how to upgrade them.
