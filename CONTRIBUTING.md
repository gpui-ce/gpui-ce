# Contributing to GPUI-CE

Report a bug, contribute an example, improve the docs, or send a code change.
Discuss larger API or architecture changes before writing the implementation:
[open an issue](https://github.com/gpui-ce/gpui-ce/issues) or join the
[Discord](https://discord.gg/ENGHGjrYEn).

Use the [setup guide](SETUP.md) to build the repository and run examples.

Rustdoc includes the tutorial, guides, and concepts alongside the API reference.
Doctests compile or run their snippets; Cargo checks the complete example
programs. See [Writing GPUI documentation](docs/writing-docs.md) for the source
layout, prose conventions, and commands to run before submitting a docs change.
