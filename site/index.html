What GPUI gives you

Developed for the Zed editor, GPUI provides the building blocks for custom application interfaces.

Rendered on the GPU

Layout and painting produce a scene of batched shapes, text, and images for the platform renderer.

Flexbox and grid

Flexbox and grid, styled with methods like .flex(), .gap_4() and .rounded_lg().

State with one owner

The app owns entity state. Contexts provide access, and notifications connect changes to observers and rendering.

Keyboard first

Typed actions, key bindings with contexts, and focus handling are built in.

Motion

Animate elements and style changes with easing and springs. A shared setting lets the app reduce motion.

Made to be tested

Drive views headlessly with simulated input and a deterministic scheduler.
